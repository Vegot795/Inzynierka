Praca inżynierska - Projekt gry 2D typu top-down shooter implementujący proceduralność poziomów wraz z systemem aktywności przeciwników w silniku Unity

Autor: Davies Ogunruku

Cel gry:

Aby ukończyć grę, należy pokonać wszystkich wrogów na mapie, nie odpuszczając do śmierci gracza. Gracz ma do wyboru wiele broni oraz granatów, za pomocą których może ukończyć zadanie. Zależnie od poziomu trudności, poziom wytrzymałości gracza spadnie, a aktywność przeciwników wzrośnie.

Techniczne:
Gra jest tworzona w silniku Unity w stylu Pixel art z punkem widzenia typu topdown. Zaimplementowane zostaną mechaniki:
- System aktywności przeciwników (Behavior tree + Finite state machine)
- Proceduralne generowanie poziomów (Binary Space Partitioning)
